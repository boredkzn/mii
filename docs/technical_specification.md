# ТЗ — MenuBoard (ДЗ4, Шаг 1)

**Студент:** Суханова Ксения Львовна  
**Стек:** React + Vite + TypeScript + Tailwind CSS  
**UI:** Tailwind + собственная палитра (лес / глина / крем)

## Цель

Фронтенд меню корпоративной столовой: сотрудник видит блюда дня, учитывает аллергены и собирает предварительный выбор.

## Аудитория

Сотрудники офиса, питающиеся в столовой «Зелёный угол».

## Функции (минимум 3)

1. **Меню по дням** — вкладки Пн–Пт, карточки блюд.
2. **Выбор «Возьму»** — список выбранных, сумма ₽ и ккал, состояния UI.
3. **Фильтры** — тип (суп/горячее/салат/напиток) и скрытие аллергена.

## Нефункциональные

- Адаптив sm: две колонки карточек.
- Только mock-данные.
- Vitest ≥ 3 теста.
- Визуально не копировать KeyCabinet.

## Вне скоупа

Оплата, бронирование порций на кухне, авторизация.
