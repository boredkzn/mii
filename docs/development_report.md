## 2. Работа с AI

- Старт: «спроектируй MenuBoard для столовой: дни недели, аллергены, выбор блюд».
- Итерации по карточке: цена, калории, кнопка «Возьму» / «Убрать».
- CoT для фильтра: (1) день → (2) тип → (3) аллерген → (4) сумма выбора.
- Мультимодальная отладка по описанию: «на 375px вкладки дней обрезаются» → overflow-x-auto.
